# Solana-Rust-
# 🦀 Solana × Rust Learning

Learning Solana development with Rust from scratch.

---

## 🎯 What We'll Learn

- **Rust** - Variables, functions, ownership, structs
- **Solana** - Accounts, PDAs, transactions, SPL tokens
- **Anchor** - Framework for building Solana programs
- **Build** - Counter, Todo, Vault, NFT Minter, AMM

---

## 🛠️ Tools We'll Use

| Tool | What it does |
|------|--------------|
| Rust | Smart contract language |
| Solana CLI | Deploy and interact with blockchain |
| Anchor | Framework for Solana programs |
| cargo | Rust package manager |
